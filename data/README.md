# Dataset Documentation: AI4I 2020 Predictive Maintenance Dataset

## 1. Provenance and Overview
- **Dataset Name:** AI4I 2020 Predictive Maintenance Dataset
- **Curator:** Stephan Matzka, School of Engineering - Technology and Life, HTW Berlin, Germany
- **Original Repository:** [UCI Machine Learning Repository (ID: 601)](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)
- **Year:** 2020
- **Instances:** 10,000 recorded operational machine cycles
- **Attributes:** 14 columns (1 identifier, 1 product variant code, 1 quality type, 5 operational sensor measurements, 1 global failure target, and 5 specific mechanical failure modes).

## 2. Important Notice on Synthetic Data Generation
> [!IMPORTANT]
> The AI4I 2020 dataset is a **synthetic dataset** designed to realistically reflect predictive maintenance scenarios encountered in industrial milling tools. 
> While the numerical distributions and mathematical physical failure modes (heat dissipation gradients, electrical power limits, tool wear strain) mirror empirical physics equations, **it does not represent raw sensor logs collected from a live physical factory floor**.
> 
> In this repository, actual values from the official UCI repository are strictly preserved without fabricated records or artificial inflation.

## 3. Data Dictionary & Engineering Units

| Column Name | Data Type | Physical Engineering Unit | Description |
| :--- | :--- | :--- | :--- |
| `UDI` | Integer | None | Unique sequential row index (1 to 10,000). |
| `Product ID` | String | None | Serial identifier prefixed with quality variant (L/M/H) followed by variant sequence. |
| `Type` | String | Categorical (`L`, `M`, `H`) | Product quality variant: Low (60% volume), Medium (30% volume), High (10% volume). |
| `Air temperature [K]` | Float | Kelvin (K) | Ambient room temperature surrounding the machine (mean ~300.0 K, std ~2.0 K). |
| `Process temperature [K]`| Float | Kelvin (K) | Machining process temperature generated by cutting friction (~305.7 K to 313.8 K). |
| `Rotational speed [rpm]` | Integer | Revolutions per minute (rpm) | Spindle angular velocity calculated for a 2860 W spindle (~1,168 to 2,886 rpm). |
| `Torque [Nm]` | Float | Newton-meters (Nm) | Spindle cutting torque normally distributed around 40 Nm (~3.8 to 76.6 Nm). |
| `Tool wear [min]` | Integer | Minutes (min) | Cumulative active machining time on the cutting insert (0 to 253 min). |
| `Machine failure` | Binary (0/1)| Dimensionless | Ground truth failure indicator (1 = machine breakdown, 0 = nominal operation). |
| `TWF` | Binary (0/1)| Dimensionless | **Tool Wear Failure:** Tool breaks or exceeds safe wear limit (between 200 and 240 min). |
| `HDF` | Binary (0/1)| Dimensionless | **Heat Dissipation Failure:** Occurs if (Process Temp - Air Temp) < 8.6 K and Speed < 1,380 rpm. |
| `PWF` | Binary (0/1)| Dimensionless | **Power Failure:** Occurs if spindle power ($Torque \times \omega$) < 3,500 W or > 9,000 W. |
| `OSF` | Binary (0/1)| Dimensionless | **Overstrain Failure:** Occurs if ($Tool\ Wear \times Torque$) exceeds variant threshold (11k L, 12k M, 13k H). |
| `RNF` | Binary (0/1)| Dimensionless | **Random Failure:** Stochastic independent breakdown with probability ~0.1%. |

## 4. Class Distribution & Imbalance
- **Total Records:** 10,000
- **Normal Operations (0):** 9,661 (96.61%)
- **Machine Failures (1):** 339 (3.39%)
- **Failure Breakdown by Mode:**
  - `HDF`: 115 records (1.15%)
  - `OSF`: 98 records (0.98%)
  - `PWF`: 95 records (0.95%)
  - `TWF`: 46 records (0.46%)
  - `RNF`: 19 records (0.19%)
  *(Note: A single incident can exhibit multiple coincident failure modes, or occur without one of the five specific heuristic triggers).*

## 5. Automated and Manual Download Instructions
### Automated Download
Run the automated downloader script from the repository root:
```bash
python src/download_dataset.py
```
This script queries the UCI Machine Learning Repository static zip file and verifies checksum and schema.

### Manual Download
If automated network queries are restricted by proxy or firewall:
1. Navigate to: `https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset`
2. Click **Download** to obtain `ai4i+2020+predictive+maintenance+dataset.zip`.
3. Extract `ai4i2020.csv` directly into the `data/` folder of this project:
   ```
   predictive-maintenance-dashboard/
   └── data/
       └── ai4i2020.csv
   ```
4. Verify the file size is ~490 KB and contains 10,000 rows.
